# 💺 OmniSeat — Dynamic Hall Booking System

OmniSeat is a comprehensive venue management platform that allows users to design and manage complex seating arrangements with ease. From grand symphony halls to local cinemas, OmniSeat provides a flexible, powerful interface for hall setup and ticket booking.

### ✨ Key Features:
* **Interactive Hall Configurator:** Drag-and-drop sections to create custom venue layouts.
* **Advanced Design Tools:** Customize row curves, seat spacing, rotation, and numbering strategies.
* **Real-time Seat Selection:** Seamless "click-to-book" experience with different seat states (Available, Selected, Booked).
* **Slot Management:** Planned module for scheduling shows and dynamic session pricing.
* **Web-Ready View:** A clean, read-only interface for customers to select their seats live.
* **High Performance:** Powered by Konva.js for smooth handling of thousands of seats on a single canvas.
